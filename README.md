# FoVia Script
本格的なスクリプト言語を作りたい！
とおもってるおもちゃリポジトリ.

## アイデンティティ
1. 安全性(証明的)
2. 速度
3. インタプリタの美しさ わかりやすさ
4. 柔軟性
5. 書き心地
6. モダン文法
7. 技術的挑戦

1を達成すれば2も3も4も5も達成される  
という風に相互関係があると思う
